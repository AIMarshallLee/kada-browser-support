KADA AI Skills Privacy Policy

Kunlun Growth · Version 0.1.0

The extension stores saved Markdown, skill names and categories, favorites, and the language preference in local extension storage in your browser profile. The extension reads text from a Markdown file you select. It does not upload the file or your saved data. There is no analytics, account, or remote execution. The extension does not read the pages you visit.

When you select Copy instructions, the extension writes the text in the editor to your device clipboard. Any app or service you later paste it into processes that text under its own terms. To delete a personal skill, select it and click Delete. Data stays in the browser profile until deleted or extension storage is cleared by uninstalling.

You can contact dasean@yeah.net about privacy. If you email us, we receive the address and message you choose to send in order to respond.

KADA AI Skills 隐私政策

扩展在此浏览器配置的本地存储中保留已保存的 Markdown 指令、名称和分类、收藏和语言设置。扩展仅在你主动选择 Markdown 文件时读取其中的文本。扩展没有账号、统计追踪、服务器上传或远程执行，也不读取你浏览的网页。

点击「复制指令」时，扩展将编辑区文本写入设备剪贴板。你粘贴到其他服务后，由该服务按其条款处理文本。选择个人技能并点击「删除」可移除该条目，卸载扩展可清除该配置中的扩展数据。

隐私问题请联系 dasean@yeah.net。来信的地址和内容将用于回复。
