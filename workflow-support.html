KADA Workflow Support

Open KADA Workflow from the extension toolbar. Start recording and use sample data in the built-in task board. After you stop, edit or remove steps and save the workflow. Replay uses the current board state. Clear the board to start from an empty board. The last replay log describes the first failure and the completed steps. Only the extension's board is supported.

Send feedback to dasean@yeah.net with your browser and extension versions and steps using sample labels.

技术支持

从扩展工具栏打开 KADA Workflow。开始录制后，在内置练习看板使用示例数据。停止后可以编辑或移除步骤，再保存流程。重放基于当前看板，若需要从空看板开始，请先清空。日志列出完成的步骤及首个失败原因。反馈请注明浏览器、扩展版本和使用示例数据的重现步骤。
