KADA Web to Data Support

Open the extension on the page you want to export, find tables, and select a table from the list. Browser settings pages, iframe contents, and non-HTML data grids are outside the supported scope. Change the field selection and enable deduplication before downloading. If a table changed, find tables again.

Email dasean@yeah.net with your browser and extension versions, the steps, and a sample table with private values removed.

技术支持

在目标页打开扩展后，查找并选择表格，再调整字段和去重后下载。浏览器设置页、内嵌框架和非 HTML 的数据网格不在支持范围内。表格变化时请重新查找。反馈时请提供浏览器和扩展版本、重现步骤及已脱敏的表格样例。
